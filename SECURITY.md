# Security

The hosted server is [https://mcp.edgaze.ai](https://mcp.edgaze.ai). This repository publishes manifests only.

## Report a vulnerability

Email `security@edgaze.ai`. Do not open a public issue.

Include the affected URL or manifest, steps to reproduce, impact, and a contact.

We acknowledge reports and fix hosted issues in the Edgaze product. Manifest fixes land here after review.

## What this server asks for

OAuth consent is **Find workflows** and **Run workflows**. There is no API key in these manifests. Do not add a bearer token to make the server "work."
